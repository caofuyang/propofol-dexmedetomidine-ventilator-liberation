# MIMIC-IV 序贯 landmark 调整后关联分析

## 主结果

主分析包含 54,980 个序贯试验实例（11,201 名患者、12,320 个 ICU 住院次），其中转换策略 994 个、继续丙泊酚 53,986 个。

重叠加权后，继续丙泊酚组 48 小时内稳定成功拔管风险为 33.3%，转换组为 44.5%。风险差为 11.28 个百分点（95% 区间 8.14 至 14.01），风险比为 1.34（95% 区间 1.24 至 1.42）。

## 诊断

- 加权前最大绝对 SMD：0.350。
- 加权后最大绝对 SMD：0.060。
- 转换组有效样本量：992.6；继续组有效样本量：26153.5。
- 转换组倾向评分 1%–99%：0.0034–0.1805。
- 继续组倾向评分 1%–99%：0.0014–0.0893。

## 解释边界

这是严格 6 小时策略评估窗完成后的序贯 landmark 估计；转换组要求窗口末仍有原始右美托咪定记录覆盖，继续组要求整个窗口无间断原始丙泊酚记录覆盖。主分析置信区间采用 300 次患者整簇有放回重抽样，并在每次重复中重新执行变量筛选、插补、缩放、编码和倾向模型拟合；敏感性分析区间以已估计权重为条件。

该结果只能解释为目标重叠人群中的调整后关联。主策略允许窗口后治疗变化；排除后续右美托咪定的分析使用了未来治疗信息，仅是交叉用药诊断。即使敏感性分析方向一致，也不能排除未记录的撤机准备度、气道保护能力和临床治疗意图造成的残余混杂，不能升级为强因果表述。
